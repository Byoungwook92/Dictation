Google Gemini 무료 API 키 설정

• Google AI Studio(aistudio.google.com)에서 결제 카드 등록 없이 무료로 발급받은 API 키를 등록합니다.
• 확실한 무료 등급(Free of charge) 모델만 포함되어 있으며, 저장된 키는 화면·인쇄물·내보내는 백업 파일에 절대 노출되지 않습니다.

저장된 문제 묶음 보관함

생성한 문제와 난이도별 글자 수 설정은 브라우저에 자동 저장되며, 파일(.json)로 내보내어 컴퓨터에 보관할 수도 있습니다(API 키는 제외됨). 저장된 문제 묶음을 열면 자동으로 재생성하지 않고 당시 문항을 그대로 보여줍니다. (누적 중복 방지 문장 이력: 0문장)

1. 출제 조건 선택

자 이내 (공백 포함, 12~100자)

단문·간단한 이어진문장, 핵심 맞춤법·띄어쓰기 요소 1~2개

직접 입력: 문항 (양의 정수, 1~30)

확실한 무료 등급(Free of charge) 모델만 표시됩니다. 과부하(503) 시 다음 무료 모델로 즉시 우회합니다.

출제 기준: 혼동 표기(되·돼, 안·않 등), 조사·의존명사 띄어쓰기, 어미 활용, 자주 틀리는 어휘를 지정한 최대 글자 수 이내로 빠르게 출제합니다.
공유용 듣기 전용 주소 (이 주소를 보내면 상대방은 정답이 가려진 듣기 화면으로 열립니다)

※ 내 컴퓨터 파일(file://) 상태에서는 같은 컴퓨터의 브라우저에서만 열립니다. 이 HTML 파일을 GitHub Pages·Netlify·Cloudflare Pages 같은 무료 웹 호스팅에 올려두면 학생·학부모가 스마트폰에서도 링크 하나로 바로 들을 수 있습니다. (API 키는 링크에 절대 포함되지 않습니다.)
